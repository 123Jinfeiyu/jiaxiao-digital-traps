# 数字陷阱 · 科目一 C2 交通标志与记分题

单文件驾考刷题页：交通标志图库 + 「记分 / 罚款 / 速度 / 距离 / 年限」数字混淆专项。

- 709 道真题，409 张题图，全部内嵌在 `index.html`（base64），离线可用
- 纯前端零依赖，答题进度存 `localStorage`
- 移动端优先布局，可加到主屏当 App

> 题面与解析来自公开驾考资料，仅作个人复习使用；如需公开分发请自行确认版权。

## 使用

浏览器直接打开 `index.html`。文件较大（8.7 MB），首次加载稍慢，之后离线可用。
